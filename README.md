# Students Management System

A simple command-line based Student Management System that allows users to add student details, calculate their average marks, and track whether they have passed or failed based on their average. The system also provides features to display the total number of students, the number of students who passed, and detailed student information.

## Features

- Add student information (name, marks for various courses)
- Calculate student's average marks
- Check if a student has passed (average ≥ 50)
- Display the total number of students
- Display the number of students who passed
- List all students' information

## Requirements

- Python 3.x
- No external libraries are required.

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/TukaHeba/Simple-Student-System.git
2. Navigate to the project directory:
   ```bash
   cd Simple-Student-System
3. Run the main.py file:
   ```bash
   python main.py
4. Follow the on-screen instructions to add student details and view the results.
